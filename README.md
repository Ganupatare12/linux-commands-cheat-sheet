command        uses
1)  pwd    =  print working directory
2)  cd     =  changing directory
3)  ls     =  list of files and directory
4)  mkdir  =  make directory
5)  touch  =  make empty file
6)  cp     =  copy file or directory
7)  mv     =  move file or directory
8)  rm     =  remove file
9)  rmdir  =  remove directory
10) cat    =  print file content
11) man    =  manual page
12) grep   =  search text pattern in file
13) find   =  locate files 
14) history = see past commands 
15) chmod  =  change permission file or directory
